# 疑難排解

[返回首頁](../README.md) · [使用手冊](USER_GUIDE.md)

## 安裝未完成

確認為 macOS，已安裝 Homebrew、Python 3.10 以上及 Xcode Command Line Tools。`install.command` 的視窗會保留實際錯誤。需要 Swift 編譯器才能建立原生視窗；安裝程式不會代替使用者同意 Apple 安裝提示。

若下載的腳本被系統阻擋，先檢視來源，再依 macOS 的標準允許流程處理。工具不會自動關閉 Gatekeeper 或修改系統授權資料庫。

若提示目前仍有任務，先等下載完成或從工具取消任務，再安裝。

## Spotlight 找不到

先在捷徑 App 確認捷徑名為 `youtube downloader`，可直接執行，詳細資訊開啟「在 Spotlight 中顯示」。必要時嘗試 Spotlight 的動作篩選。設定與搜尋索引行為會受 macOS 版本影響，完整新帳號流程尚未驗證。

## 無法讀取桌面或沒有通知

依 macOS 提示允許桌面檔案存取，並確認捷徑允許執行指令稿。通知還會受系統通知設定與專注模式影響；沒有通知時仍可從工具查看任務結果。

## 下載失敗或進度不動

先在進度頁開啟結果，確認是整份清單讀取失敗，還是部分歌曲失敗。私人、已刪除、需要登入或 YouTube 驗證限制的內容可能無法下載。工具不會自動讀取瀏覽器 Cookie。

確認網路與網址；YouTube 格式變更時，先等任務結束，再使用 `update.command` 更新 yt-dlp 與 Deno，接著重試。轉碼、封面處理或等候網路時，不一定能顯示當首百分比。

磁碟不足時先騰出空間，再重試。缺少 ffmpeg／ffprobe 時，確認 Homebrew 安裝狀態，必要時重新執行安裝腳本。

## Mix 清單無法讀取

從歌曲的播放頁複製完整網址，應含 `v=` 與 `list=`。Mix 是動態推薦，必須選定首數；不能以全部方式下載。重試既有任務時仍使用先前保存的清單快照。

## 沒有存進我選的分類

若同一影片已存在其他分類，工具會跳過並回報原位置，不會偷偷複製或搬動。手動序號分類優先於鋼琴規則；鋼琴規則優先於預設分類。

## 關閉視窗後還在下載

這是背景下載的預期行為。要停止，重新開啟工具的任務管理，選取消並確認。

## 技術記錄位置

在 Finder 使用「前往資料夾」，輸入：

```text
~/Library/Application Support/MusicDownloader/
```

`logs/` 保存技術輸出，`reports/` 保存任務結果，`config.json` 記錄安裝時解析的路徑。一般使用不需要手動編輯 SQLite。

若回報問題，描述操作步驟、預期與實際結果，附 macOS 及工具版本；只提供與錯誤相關的片段，省略個人路徑與播放清單資料。
