# 使用手冊

[返回首頁](../README.md) · [安裝與捷徑設定](../SHORTCUT_SETUP.md) · [疑難排解](TROUBLESHOOTING.md)

## 第一次使用

先依 README 完成環境、安裝腳本及捷徑設定。按 ⌘ + Space 搜尋 **youtube downloader**；若 Spotlight 尚未列出，先從捷徑 App 執行，確認捷徑詳細資訊已開啟 Spotlight 顯示。

日常下載都在原生視窗中完成，不需開啟 Terminal。

## 下載單首

1. 複製 YouTube／YouTube Music 的影片或歌曲網址。
2. 執行工具，選「下載單首」。剪貼簿有有效網址時使用剪貼簿，否則會詢問網址。
3. 選擇現有分類或新增分類，依視窗設定需要的分類方式。
4. 檢查確認摘要，選擇開始下載。

網址即使帶播放清單參數，單首模式也只處理指定影片。

## 下載播放清單

1. 選「下載整份播放清單」，提供包含清單 ID 的網址。
2. 選下載首數。一般清單可填 1–10000 下載前 N 首，或填 0 下載全部；Mix／Radio 必須填 1–500 首，不支援全部。
3. 選預設分類。可以把整份清單放進同一分類，也可依歌曲序號或範圍指定其他分類。
4. 檢查摘要中的網址、數量與分類，確認後開始下載；需要調整時返回修改。

Mix 網址應從歌曲播放頁複製，包含 `v` 和 `list`。只有部分含種子影片 ID 的 Mix 可自動修復；不含種子的推薦清單網址需要重新複製完整網址。

## 分類例子

例如：預設分類選「英文」，將第 1–5 首指定為「日文」，第 8 首指定為「古典」。未指定的歌曲仍存到英文。啟用鋼琴自動分類後，未手動指定且標題符合的歌曲存入鋼琴。

採用順序為 **手動指定 → 鋼琴標題規則 → 預設分類**。序號是清單原始位置；失敗或被跳過的項目仍占序號，不會讓後面的歌曲重新編號。分類名稱不可包含斜線、冒號或控制字元。

鋼琴規則只讀影片標題，沒有分析音訊；標題未提樂器或用詞不準確時可能漏判、誤判。

## 查看進度、取消與重試

提交後會顯示原生進度視窗，分別顯示整體與當首進度。轉碼或等待網路時可能顯示不定進度，這時沒有可可靠計算的下載百分比。

- 關閉進度視窗或捷徑，已提交任務繼續在背景執行。
- 再執行捷徑，選「查看進度／重試／取消」，可重新開啟進度或查看結果。
- 搜尋及只看失敗可協助找出需要處理的項目。
- 要停止任務，使用取消功能並確認；已完成歌曲保留。
- 重試沿用原清單快照、首數及分類設定，只處理尚未完成項目。要換清單範圍或取得最新推薦，請建立新任務。

Mac 睡眠時下載暫停；喚醒後視網路恢復。登出或關機時無法下載，重新登入後會恢復未完成任務。

## 歌曲存在哪裡

```text
桌面／音樂／
├── 日文／歌曲.mp3
├── 英文／歌曲.mp3
└── 鋼琴／歌曲.mp3
```

沒有播放清單子資料夾。安裝程式讓 macOS 解析桌面位置，支援系統已設定的桌面路徑；真實 iCloud Desktop 完整下載尚未完成實機驗證。

可使用 Cog 等支援資料夾瀏覽的播放器，將「桌面／音樂」設為來源。播放器不包含在此安裝包內。

## 重複歌曲怎麼辦

同一影片已有有效音檔時，全域跳過並回報原位置，即使在另一分類也不搬動。原檔已消失時可重新取得。不同影片的相同位元可在下載後比對；不同編碼或標籤不保證相同，不會只憑歌名合併 Live、Cover 或 Remix。

## 更新

等下載任務完成後，雙擊 `update.command` 更新 yt-dlp 與 Deno。若要更新本專案程式，下載新版本後，依 README 的安裝方式重新安裝。重新安裝應在沒有進行中任務時執行；既有 SQLite 與音樂不會由安裝程式清空。
